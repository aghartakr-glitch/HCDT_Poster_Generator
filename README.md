# HCDT Poster Generator

A4 poster tool for the UNIST Department of Human-Centered Design + Technology (N-FUD 2026 visual identity).

- Grid: 14mm margin, 4 columns (gutter 4mm), 14 rows (gutter 4mm)
- Only approved color combinations (guide Applications A–E, plus the white base)
- Only approved logos (horizontal, vertical) and graphics (via the 6 templates)
- Export: PDF (A4, 300dpi), PNG, project file (.json)

Live: GitHub Pages, deployed by `.github/workflows/pages.yml` on every push to `main`.

Helvetica Neue LT Std must be installed on the computer to print Helvetica Neue; otherwise Latin text falls back to Arial. Spoqa Han Sans Neo (OFL) is embedded for Korean.
